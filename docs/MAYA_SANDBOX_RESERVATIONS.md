# Maya Checkout integration (archived)

Maya Checkout is **not the current reservation payment flow**. New reservations use the local simulator described in [Local Simulated Payments](LOCAL_SIMULATED_PAYMENTS.md). That guide contains the current commands, demo card and verification behavior, timeout cases, and expected output.

The Maya API files and this page remain in the repository as historical integration work. Existing Maya checkout records and holds are retained for audit and may require the original Maya sandbox account to reconcile. Enabling local simulated payments does not cancel those hosted sessions or convert them into paid reservations.
