# Xendit integration (archived)

Xendit is **not the current reservation payment flow**. New reservations use the local simulator described in [Local Simulated Payments](LOCAL_SIMULATED_PAYMENTS.md). That guide contains the current launch commands, payment scenarios, and expected output.

The Xendit API files and this page remain in the repository as historical integration work. Existing Xendit checkout records and holds are retained for audit and may require the original Xendit test credentials to reconcile. Enabling local simulated payments does not cancel those hosted sessions or convert them into paid reservations.
