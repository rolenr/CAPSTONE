# Sectional bay model

`weights/best.pt` is the checkpoint loaded by `computer_vision/sectional_occupancy.py`. `weights/last.pt` and the plots, samples, and `results.csv` are retained training artifacts.

`args.yaml` records the original training environment. Its `/content/...` paths are historical and are not runtime paths in this repository. Run inference from the project root using the model path above.
